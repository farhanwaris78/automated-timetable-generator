How to use

  1. Generate grid - set working hours, class length and break, then build the week.
  2. Drag & drop a course from the left panel into a room/time cell.
  3. The server checks room, instructor, student and capacity clashes on every drop and explains exactly who clashes.
  4. Click a scheduled class to see the instructor, department and full student roster.
  5. Save to database stores the week; Load saved brings it back on the next launch.
  6. Export the finished week as PDF or CSV.

Keyboard: Esc closes dialogs, Delete removes the selected class, Ctrl+S saves.
